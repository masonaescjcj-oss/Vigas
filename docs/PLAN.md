# Vigas — پلن صفر تا صد

این سند نقشه‌ی کامل ساخت Vigas است: از معماری و پوشه‌ها تا انتشار اپ در فروشگاه. هر فاز خروجی مشخص دارد و ستون «وضعیت» نشان می‌دهد چه چیزی ساخته شده.

راهنمای وضعیت: ✅ ساخته شد · 🟡 نسخه‌ی اولیه ساخته شد، کار دارد · ⬜ هنوز شروع نشده

## ۱. معماری

| بخش | تکنولوژی | چرا |
|---|---|---|
| اپ اندروید | **React Native + Expo (SDK 58) + Expo Router** | یک کدبیس برای اندروید (و بعداً iOS)، بیلد ابری با EAS، آپدیت سریع بدون انتشار مجدد. |
| وب‌سایت و وب‌اپ | **Next.js 16 (React)** | سئو مهم‌ترین نیاز سایت است: رندر سمت سرور، متادیتای هر صفحه، sitemap و داده‌ی ساختاریافته (JSON-LD). React Native Web برای سایت محتوایی HTML غیرمعنایی و سنگین‌تری می‌سازد. وب هم React است، پس منطق و داده بین وب و اپ مشترک می‌ماند. |
| API Gateway | **Hono روی Node.js** (سرویس جدا، `api.vigas.ai`) | سبک و سریع، مناسب استریم. سازگار با OpenAI، مثل OpenRouter. |
| دیتابیس | **PostgreSQL 16 + Drizzle ORM** | تراکنش‌های امن برای کیف پول و اعتبار، و اسکیمای تایپ‌شده. |
| مونوریپو | **pnpm + Turborepo** | کد مشترک بین وب، اپ و گیت‌وی. بیلد و تست موازی. |

```
                 ┌──────────────┐        ┌───────────────┐
  کاربر وب  ───▶ │  apps/web    │        │  apps/mobile  │ ◀─── کاربر اندروید
                 │  Next.js     │ ◀──────│  Expo / RN    │
                 │  سایت + API  │  /api/app/*            │
                 └──────┬───────┘        └───────────────┘
                        │ (چت و Arena)
  توسعه‌دهنده ─────────▶ ┌──────────────┐     ┌─────────────────────────┐
  (کلید API)            │ apps/gateway │ ──▶ │ OpenAI, Anthropic, Google│
                        │  Hono        │     │ DeepSeek, Moonshot, …   │
                        └──────┬───────┘     └─────────────────────────┘
                               │
                        ┌──────▼───────┐
                        │  PostgreSQL  │
                        └──────────────┘
```

### پوشه‌ها

```
apps/
  web/        وب‌سایت و وب‌اپ (Next.js)
  mobile/     اپ اندروید (Expo / React Native)
  gateway/    API سازگار با OpenAI (Hono)
packages/
  core/       منطق مشترک: قیمت و پول، مسیریابی مدل‌ها، رتبه‌بندی (Bradley–Terry)، مرز Pareto
  tokens/     رنگ‌ها، فونت‌ها و فاصله‌ها از طراحی
  db/         اسکیمای دیتابیس، مایگریشن و داده‌ی اولیه
  api-client/ قرارداد و کلاینت تایپ‌شده‌ی API اپ (برای اندروید و وب)
docs/         همین پلن و مستندات
design/       پروتوتایپ‌های طراحی
```

## ۳. تصمیم‌هایی که با شماست

1. **درگاه پرداخت:** Stripe، پرداخت کریپتو، یا درگاه ایرانی. لایه‌ی پرداخت طوری ساخته شده که هر کدام را بشود وصل کرد.
2. **هاست:** پیشنهاد من: وب روی Vercel یا سرور خودتان، گیت‌وی روی یک سرور (مثلاً Hetzner یا Fly.io)، دیتابیس مدیریت‌شده (مثلاً Neon).
3. **فروشگاه اندروید:** Google Play، کافه‌بازار، مایکت، یا همه.
4. **کارمزد پلتفرم:** فعلاً ۵٪ روی شارژ اعتبار، به‌جز ۵ دلار اول. قابل تغییر در تنظیمات.
5. **کلیدهای ارائه‌دهنده‌ها:** برای فعال شدن مدل‌های واقعی، کلید API هر ارائه‌دهنده لازم است. تا آن موقع ارائه‌دهنده‌ی Mock جواب می‌دهد.
6. **زبان:** سایت فعلاً انگلیسی است. نسخه‌ی فارسی در فاز ۹.

## ۴. ریسک‌ها

- **شرایط ارائه‌دهنده‌ها و تحریم‌ها:** OpenAI، Anthropic و Google فقط در کشورهای مشخصی سرویس می‌دهند و فروش مجدد دسترسی شرایط خودش را دارد. قبل از لانچ، شرایط استفاده‌ی هر ارائه‌دهنده و محدودیت‌های تحریمی را بررسی کنید.
- **کپی‌رایت اخبار:** خبرها باید نوشته‌ی خود Vigas باشند، با لینک به منبع، نه کپی متن.
- **اعتبار لیدربورد:** بدون ضد تقلب، رأی‌ها قابل دستکاری است (فاز ۷).
- **هزینه‌ی Arena:** هر نبرد دو درخواست مدل است که هزینه‌اش با پلتفرم است. سقف روزانه برای هر کاربر لازم است (پیاده‌سازی شده: قابل تنظیم).
