questions

Before you start.

What is RetroAI?

An AI app with two modes. Chat is a general assistant that searches the live web and cites its sources. Build is an agent that turns a description into a working app.

Is RetroAI free?

You can start free, with no card. The free plan has daily limits; paid plans raise them.

Which AI models does it use?

Chat answers through You.com's web search by default, and Build uses GPT-5.6 Terra. You can also add your own key from any OpenAI-compatible provider.

Does it understand Persian?

Yes. Ask in Persian and the answer comes back in Persian, laid out right to left, with code and file names kept in the right order.

Where does the code it writes run?

In an isolated cloud sandbox for each project. You can download everything as a zip whenever you like.

Can I use it on my phone?

Yes. It runs in any mobile browser and can be added to your home screen, where it opens like an app.

Start with a question.

It's free to try and runs in your browser. Your first answer is a few seconds away.
